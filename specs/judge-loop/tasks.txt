T1: create scripts/ralph-judge.sh — the guardrail apply-cycle (READ specs/judge-loop/spec.md §§3-4,6,8 first; the CONTRACT below is literal). Executable bash, shebang /usr/bin/env bash, set -uo pipefail. Usage: ralph-judge.sh <spec-dir>, run from the TARGET repo root (which may be a different repo than the one holding this script). Env knobs with defaults: JUDGE_CMD (REQUIRED, no default — missing => usage error, exit 1), EXECUTOR_CMD (REQUIRED), GATE_SCORE="$(cd "$(dirname "$0")" && pwd)/gate-score.sh" (sibling of THIS script, never resolved from the target repo), MAX_ROUNDS=5, MAX_FINDINGS_PER_ROUND=10, JUDGE_TIMEOUT=900, EXECUTOR_TIMEOUT=600, GATE_TIMEOUT=300, JUDGE_STATE_DIR="$(git rev-parse --git-path ralph-judge)". PREFLIGHT (all fatal, exit 1, BEFORE anything else): inside a git work tree; `git status --porcelain` prints NOTHING (untracked included); "$1/spec.md" and "$1/verify.sh" exist. TIMEOUT HELPER (macOS has no coreutils timeout — write one): run_bounded <seconds> <cmd...> runs cmd in background, polls, kills -TERM then -KILL on expiry, returns 124 on timeout else the cmd's exit code. GATE RUN: gate() = STRICT=1 run_bounded "$GATE_TIMEOUT" bash "$GATE_SCORE" "$SPEC_DIR/verify.sh"; parse ONLY the LAST line matching ^---GATE-SCORE---$ and the single line immediately after it; extract passed/failed/pending/total/score/no_fail/converged/verify_rc with sed key= extraction; any missing or non-numeric field => treat as gate error => exit 1 (fail-closed; never grep the raw verifier output above the sentinel — it is untrusted and may itself contain 'score=' or a sentinel). BASELINE: run gate() TWICE; if the two (score,total,no_fail,converged,verify_rc) tuples differ => echo "gate-unstable" to stderr, exit 2; require verify_rc=0 AND converged=1 AND no_fail=1 AND total>0 else exit 1; save s_base and total_base. APPLY-CYCLE (one finding f, given as a single-line JSON string): before_head="$(git rev-parse HEAD)"; run_bounded "$EXECUTOR_TIMEOUT" $EXECUTOR_CMD "$f" (executor gets the finding JSON as its single argument and MUST NOT commit); if executor timed out or exited nonzero => RESTORE and record reject reason=executor-error and exit 1; if "$(git rev-parse HEAD)" != "$before_head" (executor committed) => RESTORE, reject reason=executor-committed, exit 1; run gate() TWICE post-mutation, tuples differ => RESTORE, record gate-unstable, exit 2; ACCEPT IFF verify_rc=0 AND converged=1 AND no_fail=1 AND total==total_base AND awk float compare score>=s_base — on accept re-check current branch equals the preflight branch, then git add -A && git commit -q -m "judge: <id> — <problem>" (id and problem from the finding); else RESTORE and reject reason=gate-regressed. RESTORE means exactly: git reset --hard "$before_head" >/dev/null && git clean -fd >/dev/null, then assert porcelain is empty again (assert failure => exit 1). Read-only outside the target repo and $JUDGE_STATE_DIR; never touch the network.
T2: extend scripts/ralph-judge.sh — the judge round, JSONL fail-closed contract, and the persistent ledger. JUDGE INVOCATION: findings_raw="$(run_bounded "$JUDGE_TIMEOUT" $JUDGE_CMD "$SPEC_DIR")"; timeout or nonzero exit => exit 1 (fail-closed, no mutation). JSONL VALIDATION (BEFORE any mutation; jq required): every nonblank line of findings_raw MUST parse as a JSON object with EXACTLY the fields id,file,category,spec_anchor,problem,suggested_change,kind (no extras, none missing); kind in {mutate,gate-gap}; category in {clarity,naming,spec-fidelity,gate-gap}; file must be a relative path containing no ".." segment; id must match ^[a-z0-9][a-z0-9-]*$; two lines with the same id but different payloads => invalid. ANY violation => print "judge-output-invalid" to stderr and exit 1 — an empty findings_raw is the ONLY valid zero-finding response (that round is DRY). LEDGER: append-only JSONL at "$JUDGE_STATE_DIR/ledger.jsonl" (mkdir -p the dir); one line per decision written BEFORE the loop proceeds: {"id":...,"decision":"accepted"|"rejected"|"gate-gap","reason":...,"round":N,"before_head":...,"after_head":...,"score":...} (after_head/score only on accepted; reason only on rejected). On startup, load every id already present into the seen-set — a finding whose id is in the ledger (ANY decision) is NEVER re-processed, across rounds AND across separate invocations of ralph-judge.sh (this is what makes a rejected finding stay rejected forever). ROUND SHAPE: validate, drop seen ids, cap the remainder at MAX_FINDINGS_PER_ROUND; every fresh kind=gate-gap finding is ledgered as decision=gate-gap (never applied, never sent to the executor); take the FIRST fresh kind=mutate finding only (one mutation per judge invocation — later mutate findings in the same response are left unledgered for a future round) and run it through the T1 apply-cycle, with one addition to ACCEPT: after the gate predicate passes, run_bounded "$JUDGE_TIMEOUT" $JUDGE_CMD --check-resolution "$f" and require its stdout to be exactly one JSON object with .id equal to the finding's id and .resolved == true — anything else (false, malformed, timeout, wrong id) => RESTORE and reject reason=not-resolved. If a round yields NO fresh mutate finding => the loop is DRY: stop.
T3: extend scripts/ralph-judge.sh — terminate + report. LOOP: for round in 1..MAX_ROUNDS run the T2 round against the CURRENT HEAD (re-invoke the judge each round; never reuse a previous round's findings list); stop early when DRY. REPORT: write "$JUDGE_STATE_DIR/report.json" via a temp file + mv (crash-safe), shape exactly {"spec_dir":...,"baseline":{"score":...,"total":...},"rounds_run":N,"accepted":[ids...],"rejected":[ids...],"gate_gaps":[ids...],"outcome":"dry"|"rounds-exhausted"|"aborted"|"gate-unstable"} — rebuild the arrays from the ledger file so the report never disagrees with it; write the report in EVERY exit path including failures (trap on EXIT is acceptable) with the outcome field telling the truth: dry (converged), rounds-exhausted (MAX_ROUNDS hit with work still flowing), aborted (any fail-closed exit 1), gate-unstable (exit 2). EXIT CODES (final): 0 = dry or rounds-exhausted (loop completed; branch is as-good-or-better and the report says what happened), 1 = aborted fail-closed (judge/executor/gate/JSONL/preflight error; tree restored), 2 = gate-unstable (flake detected; tree restored; needs a human). Print a one-line human summary to stdout at the end: "judge: N accepted, M rejected, K gate-gaps, outcome=X, report=<path>". The script stays a single file, POSIX-ish bash matching ralph-qwen.sh style, total length target under ~220 lines; shellcheck-clean enough that bash -n passes.
